SECURITY REQUIREMENTS

Policy guidelines

  • Individual accounts: Each user must have a unique account. Sharing accounts or passwords is prohibited.
  • Access permissions: Access must be limited to the information and systems required for each person’s duties. The relevant manager must approve access requests.
  • Authentication: Users must use strong, unique passwords. Multi-factor authentication must be enabled for remote access, administrator accounts and supported business services.
  • Staff changes: IT must remove access promptly when employment ends and review permissions when an employee changes roles.
  • Device protection: Company devices must run approved security software and receive security updates. Users must lock their screens when leaving devices unattended.
  • Network security: IT must maintain firewall rules, separate employee, server and management traffic, and restrict administrative access to authorised personnel.
  • Remote connections: Remote access must use an approved secure connection. Users must not expose internal systems directly to the internet without IT approval.
  • Information handling: Sensitive company, customer and employee information must be stored in approved locations and shared only with authorised recipients.
  • Software and equipment: Only authorised IT staff may install software or connect new network equipment after the required approval.
  • Backups: IT must back up critical systems, protect backup copies and test restoration according to the approved backup schedule.
  • Physical security: Server rooms and network cabinets must remain locked. Visitors requiring access must be authorised and supervised.
  • Incident reporting: Users must immediately report suspicious emails, lost devices, malware or suspected unauthorised access to the help desk. They must not attempt their own investigation.
  • Monitoring: Authorised IT staff must review security logs and alerts. Monitoring records must be protected against unauthorised access.
  • Policy breaches: Suspected breaches must be investigated and referred to management for action under AFC’s disciplinary procedures.
  • Review: The IT Manager must review this policy annually and after major incidents or significant system changes.

REPORT SECURITY CONCERNS

Contact the help desk promptly.

Follow the reporting procedure if you suspect a security incident. Never include your password in a support request.
